## 用户使用手册

欢迎使用氢课表，本手册将帮助您快速熟悉并使用软件的核心功能。

1. 账号登录
首次打开应用，您需要进行身份验证：
在登录页面输入您的教务系统学号和密码。
点击登录按钮即可进入应用首页。
注：教务系统会自动校验您的教务账号，保障您的个人数据安全。

2. 课表查看
登录成功后，您可以随时掌握自己的上课安排：
今日课表：在应用首页，可以直接看到当天的所有课程、上课时间及教室地点。
完整周课表：点击底部的课表页签，可以左右滑动查看本周及整学期的完整排课情况。

3. 成绩与考试查询
轻松获取期末成绩和考试安排，提前做好准备：
成绩查询：进入成绩页面，在顶部选择您想查看的对应学期，即可浏览各科成绩、绩点与学分详情。
考试安排：在查询页面点击考试选项，可以确认具体科目的考试日期、时间段以及考场座位号。

4. 日常与宿舍签到
如需使用签到功能，请按照以下步骤操作：
进入签到页面，界面会显示当前正在进行的签到任务。
如果页面提示需要签到密码，请先输入密码完成解锁。
解锁成功后，点击立即签到按钮，根据界面提示完成最终的操作。

5. 检查更新与常见问题
版本更新：软件在每次打开时会自动检查更新。如果弹出新版本提示，建议直接按照提示完成更新，以体验最新功能。
常见问题：如果遇到数据加载失败或白屏，请检查网络连接，或尝试彻底退出应用后重新打开。

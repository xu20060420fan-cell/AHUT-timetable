# AHUT-timetable
氢课表是一款面向安徽工业大学本科生、仅支持安卓设备的轻量课表软件，主打小而美的使用体验，无开屏广告，安装包体小、运行轻快简洁，核心功能与使用说明如下： 1. 登录绑定：进入软件后输入学号与对应密码完成账号绑定，系统会自动同步获取你的个人课表、考试安排以及成绩数据，无需手动录入课程信息。2. 今日课程首页：首页默认展示当日课程，已结束的课程会自动置灰，未进行的课程保持亮色，课程进度与状态直观清晰。3. 周课表视图：可切换至周课表页面，按周查看完整的课程排布，整周的上课时段、地点、授课老师等信息一目了然。4. 考试信息查询：内置考试查询板块，将科目按“未考”和“已考”分类展示，可查看每门考试对应的时间、考场、座位号等详细安排。
